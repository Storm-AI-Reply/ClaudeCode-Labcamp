# Workshop labs

Use this page as a **map of the whole labcamp**. Each lab has an **Overview** (prerequisites and exercise list), then **Exercise 1** and **Exercise 2**, then **Wrap-up** (verify, stretch goals, recap).

---

## All labs

| Lab | Time | Topics |
|-----|------|--------|
| [Lab 01: Execution model](lab-01/index.md) | ~30 min | Agentic loop, Plan Mode, context (`@`, `/context`, `/compact`) |
| [Lab 02: Project configuration](lab-02/index.md) | ~25 min | `CLAUDE.md`, custom slash commands |
| [Lab 03: Control & connect](lab-03/index.md) | ~30 min | Permission modes, hooks, MCP |
| [Lab 04: Scale & reuse](lab-04/index.md) | ~25 min | Subagents, skills (`SKILL.md`) |
| [Final project](../final-project.md) | ~30 min | Assemble the quiz, compete |

---

## Suggested order

1. [Setup](../setup.md) (before the labcamp)
2. Lab 01 → Lab 02 → Lab 03 → Lab 04 (in order; each builds on the last)
3. [Final project](../final-project.md)

If you get stuck in a lab, reset with `git checkout -- .` in that lab's `starter/` directory.
